### Added

- The CRD version extractor can now prove that a test or example directory is not an install source and stop letting its CRD-like files block attestation of a pair. A directory name only nominates a tree; the tree is cleared only when no install surface and no file the scan does not read could name it, at every release of both lines, and the proof is recorded in the scan. Any doubt leaves the files blocking with a typed reason. It runs only in extraction runs that attest, never in an onboarding dry run, and writes nothing to target files.
