### Added

- `prufyx-maintainer target-draft generate`: an `installPaths` entry in the rules file may carry `optional: true` with `absentTags`, for one exact definition file that older tags of the window do not carry. At a listed tag the entry is tolerated only when its absence is verified in the full local Git tree (lazy fetch disabled); a symbolic link, submodule, unreadable or opaque tree entry or a file used as a parent directory ends in the stops `optional-path-link` or `optional-path-unverifiable`, a file present at a listed tag is `optional-path-present-at-absent-tag`, a file absent at an unlisted tag keeps the stop `install-path-matches-nothing`, and absence at the newest tag is `optional-absent-at-newest`. The report lists per tag whether each optional entry was read or verified absent, and the facts digest covers it. Rules files without an optional entry behave exactly as before.
