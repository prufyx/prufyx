### Added

- `prufyx-maintainer target-draft generate`: an `installPaths` entry may carry a `role` and an inclusive tag range (`fromTag`, `toTag`) for a source that moves over time. Entries of one role must be disjoint, contiguous and cover the whole tag window exactly (`range-overlap`, `range-gap`, `range-not-covering-window`); inside its range an entry is mandatory (`range-path-absent-in-range`) and outside it the path must be absent from the full local Git tree (`range-path-present-out-of-range`); an unprovable path state is `range-path-unverifiable`. A range never combines with `optional`. The new option `--range-check-tags` applies the same check to every listed tag of each line, so a move in the middle of a line is seen. The emitted target lists the union of the paths read and its format is unchanged; `report.json` lists the entry selected per tag and the facts digest covers it. Rules files without a ranged entry behave exactly as before.
