### Fixed

- `prufyx scan` now lists every custom resource of the input in a `CUSTOM RESOURCES` section and in the JSON `customResources` array, one entry per input document: evaluated (BLOCKED or NO_FINDING, never a pass; only when every hop's decided rules name that group and kind) or NOT_EVALUATED with a typed reason (`CR_COMPONENT_VERSION_UNKNOWN`, `CR_PAIR_NOT_COVERED`, `CR_KIND_NOT_COVERED_BY_RULES`, `CR_KIND_NOT_IN_KNOWLEDGE`) and the next action. Previously a scan given only a component pair, such as cert-manager, said nothing about its custom resources. Verdict and exit codes are unchanged. The list is in the text and JSON output only, not in markdown, SARIF or CSV. The JSON field `customResources` is new in the alpha schema; a strict reader that rejects unknown fields must be updated.
