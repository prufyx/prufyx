### Changed

- Nine more reviewed rules that covered one exact version pair now cover whole release lines: opa 1.19 to 1.20, jaeger 2.19 to 2.20, cortex 1.20 to 1.21, coredns 1.13 to 1.14, envoy 1.38 to 1.39, opencost 1.119 to 1.120, opentelemetry collector 0.110 to 0.111 (two rules), and linkerd 2.13 to 2.14. The cited files, or the stated setting, were checked at the release tags named in each rule description; the evidence of a rule pins selected files at selected releases, not every file at every release. This change adds pinned citations at the missing target line ends for coredns, cortex and envoy, at the missing line ends for linkerd, and for the router and configuration watcher in opencost 1.119 to 1.120 (not its calling file). The opa rule now cites four files at the first and the last release of its target line and no file of the 1.19 line. The opencost 1.120.4 to 1.121.2 rule stays an exact version pair. Five rules are checks of the target only, or of behaviour that did not change between the lines: their range carries no release boundary and their description says so.
- The wider ranges apply to the rules, not to the native input readers. The native readers for coredns, cortex, envoy and linkerd still accept only their listed exact versions and answer UNKNOWN for other versions of the same lines; declared input is matched against the rule range.
