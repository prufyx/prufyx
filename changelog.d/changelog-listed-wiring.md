### Added

- A new line-attestation family, `changelog.listed_entries`, and one extractor per reviewed changelog row (`changelog.listed.<project>`, in `prufyx-maintainer extract list`). For the line a pair ends in, it attests that every final release of the line has a listed entry at its own release commit. It lists and judges nothing: a record names no rule, it is never a pass (no scan reads it yet), and the coverage report counts such a pair as listed in the changelog row (status stays G, never A or B, never decided). The member projects are derived from the reviewed rows (`targets.json`), and the coverage report now receives them, so the README line reports how many projects have a changelog target. A row of a form the reader does not read, or a line with one missing entry, attests nothing and gets a typed reason.
