### Added

- Maintainer extractor `crd.version-removal` 2.9.0: a reviewed exclusion of YAML or JSON files (one file or a pattern, never a directory) can declare `"defines": "none"`, and the scan checks that claim at every release. A file that is strictly decodable, holds no template syntax, no definition, no `apiextensions.k8s.io` document, no mapping that names the kind and has a `spec`, no manifest inside a string, and is no kustomization or chart is class `no-definition`, which does not block attestation. A file that fails a check keeps its class (or is `unread`) and blocks, but never withholds a pair. The install-surface guard still voids such an entry for every referrer but `//go:embed`. The loader refuses the value with `copies` or `prePatch`, on a directory, on a name other than `.json`, `.yaml` or `.yml`, on a kustomization, `Chart.yaml`, `requirements.yaml` or `values.yaml` name, and under an earlier entry that would place its files. No target uses it yet: rules, records and attestations change only by the extractor version and the code digests.
