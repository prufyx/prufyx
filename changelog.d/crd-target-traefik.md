### Added

- A CRD extractor target for Traefik (group traefik.io, ten kinds) read from the aggregate definition file in the upstream reference documentation, from 3.2 onward, with line attestation enabled. Two exclusions (a legacy-group definition file and the integration-test fixtures) are reviewed in the target with evidence pinned to the release tags v3.2.5 to v3.7.18; the fixtures hide one Traefik-owned CRD (traefikproxies.gateway.traefik.io, gateway operator test manifest) on which no claim is made. In a dry run of the derive loop, all five pairs (3.2 to 3.3 through 3.6 to 3.7) are attestable with no removals. Attested pairs appear only after the factory re-derives them and the data change passes the QA gate and data review.
