### Added

- `prufyx-maintainer onboard-bundle build` takes `--checkout DIR` with `--scan-path PATH:CLASS[:NOTE]` to record blob digests in `scan-notes.json`, limited to blobs the verified snapshot already holds (read as git objects at the snapshot commits, never the working tree; any other path is refused), and `--target-input FILE` as a capped, charset-checked hint for the target skeleton. The target draft stays a skeleton and is never filled. With a target input, an offline consistency check against the snapshot's own data writes `pass` or `fail` to the receipt (`not-run` otherwise); it verifies nothing upstream and is not coverage.
