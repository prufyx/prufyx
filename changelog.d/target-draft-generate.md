### Added

- `prufyx-maintainer target-draft generate` drafts a CRD version target from a local git checkout and a list of final release tags, with no network access. It writes the two halves of one target (half A without attestation or exclusions, half B with attestation and the pinned exclusions), a table row, a changelog text and a report naming the rule behind every decision. Paths reached through symbolic links into vendored directories become explicit paths, exclusions are emitted only when a pinned rule names them and the tree matches it, and a judgment no rule covers (a documentation-only definition source, an unpinned third-party bundle, an unreadable definition shape, a reserved or foreign-owned group) ends in a named stop with the next action. The target files are written in the exact on-disk format of the shipped targets, because they are embedded in the extractor and covered by its code digest. A foreign-group file is accepted as a third-party copy only under the extractor's default-excluded directories; anywhere else it needs a pinned rule or ends in the stop `foreign-copy-unpinned`. `--compare-a` and `--compare-b` compare the draft with a reviewed target byte for byte and exit 1 on any difference, and `--compare-report` compares the facts digest of a reviewed report. When older tags are withheld the window shrinks: the report and the command print `WARNING window-shrunk` (exit 0), and `--strict-window` turns it into the stop `window-shortened`. The drafts are written into a temporary directory and renamed, so a failed or mismatching run leaves the output directory empty.
