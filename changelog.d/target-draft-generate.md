### Added

- `prufyx-maintainer target-draft generate` drafts a CRD version target from a local git checkout and a list of final release tags, with no network access. It writes the two halves of one target (half A without attestation or exclusions, half B with attestation and the pinned exclusions), a table row, a changelog text and a report naming the rule behind every decision. Paths reached through symbolic links into vendored directories become explicit paths, exclusions are emitted only when a pinned rule names them and the tree matches it, and a judgment no rule covers (a documentation-only definition source, an unpinned third-party bundle, an unreadable definition shape, a reserved or foreign-owned group) ends in a named stop with the next action. `--compare-a` and `--compare-b` compare the draft with a reviewed target and exit 1 on any difference.
