### Fixed

- `prufyx scan` now shows the custom resource list in the Markdown, SARIF and CSV outputs as well as text and JSON. Markdown has a `Custom resources` table (apiVersion, kind, object, status, reason, next step; the first 50, then "and N more"). CSV has one `CUSTOM_RESOURCE` row per object (reason in `rule_id`, state in `title`, next step in `fix`). SARIF has a note-level result per not evaluated object with the rule id `prufyx/custom-resource/<reason>`, an error-level result for a blocked object (the blocking rule's own result; `prufyx/custom-resource/blocked` only when no finding result sits at its location), and the full list, including objects with no finding, in the run properties; an object with no finding is never a result or a pass. `--redact` applies as in the text output.
