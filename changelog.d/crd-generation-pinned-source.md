### Added

- Maintainer extractor `crd.version-removal` 2.12.0: a target may declare a generation kustomization (`"generation"`): a kubebuilder kustomization whose build output is committed under a listed path and whose own resources are not in the tree. Its directory becomes a declared definition directory, so the patch fragments below it (annotation and conversion patches of one definition) are read, each only by its bytes and only for a definition of the listed paths; the declaration decides no version. A reviewed exclusion of one `.cue` file can pin a read-only source by content digest (`"pinned": {"sha256": [...]}`): the file is an excluded finding of reason `pinned-source` while its digest holds, no template syntax and no `apiextensions.k8s.io` text, and void otherwise; the pin relaxes only the `//go:embed` check of the install-surface guard. The loader refuses malformed declarations and pins, and the target guard lists an added or changed declaration or pin. No target uses either yet: the reviewed KubeVela data (generation declaration and the pinned adopt template, expected to give four `crd.version-removal` rules for 1.8 to 1.9 after the factory re-derives it) follows in a separate change; rules, records and attestations change only by the extractor version and the code digests.
