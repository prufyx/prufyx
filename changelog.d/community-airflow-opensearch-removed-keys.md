### Added

- Community-project source rules for two projects that had none: Apache Airflow `3.0.6` to `3.1.0` (four options the 3.1.0 release notes list as removed: `[webserver] instance_name_has_markup`, `[webserver] warn_deployment_exposure`, `[api] enable_xcom_deserialize_support`, `[scheduler] dag_stale_not_seen_duration`) and OpenSearch `2.19.7` to `3.0.0` (two deprecated `gateway` settings removed in 3.0.0: `gateway.expected_nodes` and `gateway.recover_after_nodes`). `prufyx check project --project airflow|opensearch --effective-config FILE` answers BLOCKED when the selected configuration sets a removed key, PASS (scoped to those keys) when the file is declared complete and precedence-resolved and sets none, and UNKNOWN otherwise. `--effective-config` must be the plain `airflow.cfg` or `opensearch.yml`; a Helm values file or ConfigMap that wraps it is UNKNOWN or invalid input.
